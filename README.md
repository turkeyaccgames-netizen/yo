# ربات میم تلگرام

این ربات هر نیم ساعت پیج‌ها و کانال‌های میم و خنده‌دار را چک می‌کند و هر پست تازه‌ای که گذاشته باشند، با عکس و لینک برای شما در تلگرام می‌فرستد.
هر سه ساعت هم یک گزارش از پربازدیدترین پست‌های خنده‌دار و باحال می‌فرستد.

از یوتیوب فقط ویدیوهای **شورت** فرستاده می‌شود؛ ویدیوهای بلند نادیده گرفته می‌شوند.

در این راهنما همه‌ی توضیح‌ها فارسی است. فقط دستورها و اسم دکمه‌ها انگلیسی مانده‌اند، چون باید دقیقاً همان‌طور تایپ یا پیدا شوند.

---

## چه چیزهایی را چک می‌کند؟

پنج منبع:

- یوتیوب (ده کانال)
- اینستاگرام (ده پیج)
- تیک‌تاک (ده اکانت)
- ایکس، توییتر سابق (ده اکانت)
- کانال‌های عمومی تلگرام فارسی (سه کانال برای شروع: گیزمیز، Fun HipHop و کاف)

اکانت‌های چهار برنامه‌ی اول انگلیسی‌زبان و معروف‌اند. مثل 9GAG، Daily Dose Of Internet، Khaby Lame و Barstool Sports.
کانال‌های تلگرام را بهتر است با کانال‌های میم و فان مورد علاقه‌ی خودتان عوض کنید.
لیست کامل‌شان در فایل تنظیمات است و هر وقت خواستید می‌توانید کم و زیادش کنید:

```
config.toml
```

برای گرفتن اطلاعات، هیچ سرویس پولی و هیچ اکانت شخصی لازم نیست. همه‌ی راه‌ها رایگان‌اند.

---

## قدم ۱: ساختن ربات تلگرام

۱. در تلگرام این ربات رسمی را باز کنید: [@BotFather](https://t.me/BotFather)

۲. این دستور را برایش بفرستید:

```
/newbot
```

۳. یک اسم و یک آیدی برای ربات‌تان انتخاب کنید. در آخر یک رشته‌ی طولانی به شما می‌دهد که به آن **توکن** می‌گویند. چیزی شبیه این:

```
8123456789:AAH7d-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

۴. حالا ربات تازه‌ساخته‌ی خودتان را باز کنید و برایش این را بفرستید تا ربات اجازه‌ی پیام دادن به شما را داشته باشد:

```
/start
```

## قدم ۲: وارد کردن توکن

۱. در پوشه‌ی پروژه، فایل زیر را کپی کنید:

```
.env.example
```

۲. اسم فایلِ کپی‌شده را بگذارید:

```
.env
```

۳. فایل را با نوت‌پد باز کنید و توکن را جلوی خط اول بنویسید. بدون فاصله، بدون علامت نقل‌قول:

```
TELEGRAM_BOT_TOKEN=8123456789:AAH7d-xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

۴. حالا باید شماره‌ی چت خودتان را پیدا کنید. این دستور را اجرا کنید:

```bash
venv\Scripts\python main.py --chat-id
```

یک عدد به شما نشان می‌دهد. آن عدد را جلوی خط دوم فایل بنویسید:

```
TELEGRAM_CHAT_ID=123456789
```

اگر می‌خواهید پست‌ها به جای چت خصوصی، در یک **کانال** تلگرامی بیایند: ربات را ادمین آن کانال کنید، یک پیام در کانال بگذارید و دوباره دستور بالا را اجرا کنید. آیدی کانال با `-100` شروع می‌شود.

---

## قدم ۳: تست کردن

اول این دستور را بزنید. سریع است و فقط یک پیام کوتاه می‌فرستد تا ببینید اتصال به تلگرام برقرار است:

```bash
venv\Scripts\python main.py --ping
```

اگر پیام رسید، حالا این را بزنید. حدود یک دقیقه طول می‌کشد و آخرین پست هر چهار برنامه را برایتان می‌فرستد:

```bash
venv\Scripts\python main.py --sample
```

اگر چهار پیام در تلگرام گرفتید، یعنی همه چیز درست است.

اگر این پیام را دیدید، یعنی ارتباط با سرور تلگرام قطع شده و باید VPN را چک کنید:

```
ارتباط با سرور تلگرام برقرار نشد
```

## قدم ۴: اجرای خودکار و رایگان روی گیت‌هاب

تا اینجا ربات فقط وقتی کار می‌کند که خودتان دستور را اجرا کنید و کامپیوتر روشن باشد.
برای اینکه خودش هر نیم ساعت اجرا شود، آن را روی سرورهای رایگان گیت‌هاب می‌گذاریم.

۱. در سایت [github.com/new](https://github.com/new) یک مخزن (repository) بسازید و حالت آن را روی این بگذارید:

```
Public
```

مخزن عمومی، زمان اجرای نامحدود و رایگان دارد. توکن شما داخل مخزن نیست، پس کسی آن را نمی‌بیند.

۲. همه‌ی فایل‌های این پوشه را در آن مخزن آپلود کنید، **به جز** این دو مورد:

```
.env
venv
```

۳. در صفحه‌ی مخزن، از بالا این مسیر را دنبال کنید:

```
Settings → Secrets and variables → Actions → New repository secret
```

۴. دو تا رمز اضافه کنید. اسم اولی دقیقاً این باشد و مقدارش همان توکن رباتتان:

```
TELEGRAM_BOT_TOKEN
```

اسم دومی این و مقدارش همان شماره‌ی چت:

```
TELEGRAM_CHAT_ID
```

۵. به بالای صفحه‌ی مخزن برگردید و وارد این تب شوید:

```
Actions
```

از ستون سمت چپ `meme-bot` را انتخاب کنید و دکمه‌ی `Run workflow` را بزنید.

تمام. از این به بعد خودش هر نیم ساعت اجرا می‌شود، حتی وقتی کامپیوترتان خاموش است.

در اولین اجرا فقط یک پیام «ربات فعال شد» و یک گزارش ترند می‌گیرید. پست‌های قدیمی پیج‌ها برایتان فرستاده نمی‌شود، فقط از این به بعد هر چه تازه بگذارند می‌آید.

## دستورها

| دستور | کارش چیست |
|---|---|
| `python main.py` | اجرای عادی: پست‌های تازه و در صورت رسیدن وقتش، گزارش ترند |
| `python main.py --trends` | همین حالا گزارش ترند را بفرست |
| `python main.py --combos` | همین حالا ترکیب‌های پیشنهادی را بفرست |
| `python main.py --sample` | تست: آخرین پست هر چهار برنامه را بفرست |
| `python main.py --dry-run` | پیام‌ها را فقط روی صفحه نشان بده، چیزی نفرست |
| `python main.py --chat-id` | شماره‌ی چت شما را نشان بده |
| `python main.py --only instagram` | فقط یک برنامه را چک کن (بقیه را نادیده بگیر) |
| `python main.py --skip instagram` | همه را چک کن جز این یکی |
| `python main.py --ping` | تست سریع اتصال: یک پیام کوتاه بفرست |

| `python -m unittest discover tests` | تست‌های خودکار (بدون اینترنت، چند ثانیه) |

روی ویندوز اول دستورها این را بگذارید:

```
venv\Scripts\
```

یعنی مثلاً:

```bash
venv\Scripts\python main.py --trends
```

## عوض کردن پیج‌ها و تنظیمات

همه چیز در این فایل است و با نوت‌پد هم باز می‌شود:

```
config.toml
```

آنجا می‌توانید:

- پیج و کانال اضافه یا کم کنید
- تعداد پست‌هایی که از هر اکانت در هر بار فرستاده می‌شود را عوض کنید
- فاصله‌ی زمانی گزارش ترند را از سه ساعت به چیز دیگری تغییر دهید
- اگر ویدیوهای بلند یوتیوب را هم خواستید، مقدار `shorts_only` را از `true` به `false` عوض کنید

اکانتی که تازه اضافه کنید، پست‌های قدیمی‌اش یکجا برایتان نمی‌آید.

## گزارش ترند چطور ساخته می‌شود؟

- **یوتیوب:** پربازدیدترین شورت‌های بیست‌وچهار ساعت گذشته‌ی همان کانال‌ها
- **اینستاگرام:** پرلایک‌ترین پست‌های بیست‌وچهار ساعت گذشته‌ی همان پیج‌ها. اینستاگرام تعداد بازدید را بدون لاگین نشان نمی‌دهد، برای همین ملاک لایک است
- **تیک‌تاک:** ویدیوهای پربازدید فید ترند تیک‌تاک، به‌علاوه‌ی پربازدیدهای همان اکانت‌ها
- **ایکس:** پربازدیدترین توییت‌ها، به‌علاوه‌ی موضوعاتی که همان لحظه ترند هستند

### «پربازدید» یعنی نسبت به همان اکانت

ترتیب گزارش ترند فقط بر اساس تعداد بازدید نیست. ربات یادش می‌ماند هر اکانت معمولاً چقدر بازدید می‌گیرد. کلیپی که ۳۰۰ هزار بازدید دارد ولی آن پیج معمولاً ۴۰ هزار می‌گیرد، از کلیپ ۲ میلیونی پیجی که هر روز ۵ میلیون می‌گیرد بالاتر می‌آید؛ چون اولی واقعاً گل کرده.

این کلیپ‌ها در پیام با این علامت مشخص می‌شوند:

```
🚀 6.0× معمولِ این اکانت
```

چند اجرا اول این علامت دیده نمی‌شود، چون ربات هنوز سابقه‌ی کافی (حداقل پنج پستِ بیشتر از دوازده ساعت) از هر اکانت ندارد.

## ترکیب‌های آماده برای ساختن پست

هر سه ساعت، علاوه بر گزارش ترند، ده «ترکیب پیشنهادی» هم می‌آید. هر ترکیب یعنی یک متن خنده‌دار که به یک کلیپ می‌خورد و با هم بامزه‌تر می‌شوند.

در هر پیام این‌ها را می‌گیرید:

- **میم آماده‌ی انتشار**: خود کلیپ که متن با فونت درشت در یک نوار سفید بالای آن نوشته شده. مستقیم می‌شود پستش کرد
- **متن پیشنهادی** در یک کادر که با یک ضربه کپی می‌شود
- لینک کلیپ و لینک توییت، اگر خواستید منبع را ببینید
- دو دکمه‌ی **👍 خوب بود** و **👎 به درد نخورد**

اگر کلیپ خام بدون متن را می‌خواهید تا خودتان تدوین کنید، در بخش `[combos]` فایل تنظیمات مقدار `render_meme` را `false` کنید.

### دکمه‌های 👍 و 👎

ربات از رأی‌های شما یاد می‌گیرد: کلیپ‌های اکانتی که دوستش دارید بالاتر می‌آیند، و اکانتی که سه بار بیشتر از پسندیدن، رد کرده باشید دیگر در ترکیب‌ها نمی‌آید.

ربات هر نیم ساعت یک بار اجرا می‌شود، پس رأی شما در اجرای بعدی خوانده می‌شود. تا آن موقع دکمه ممکن است چند ثانیه حالت «در حال بارگذاری» نشان بدهد؛ طبیعی است. وقتی خوانده شد، جای دو دکمه «👍 ثبت شد» یا «👎 ثبت شد» می‌آید.

### انتخاب هوشمند با Claude (اختیاری)

بدون هوش مصنوعی، ربات متن و کلیپ را فقط با کلمه‌ها جفت می‌کند و خود ویدیو را نمی‌بیند. اگر یک کلید Claude بدهید:

- تصویر هر کلیپ و توضیحش را **می‌بیند** و متنی را انتخاب می‌کند که واقعاً به آن کلیپ بخورد
- اگر هیچ متنی مناسب نبود، **خودش یک متن بهتر می‌نویسد**
- متن را به **فارسی محاوره‌ای** برمی‌گرداند، نه ترجمه‌ی کلمه‌به‌کلمه، و همان فارسی روی میم نوشته می‌شود. متن انگلیسی اصلی هم زیرش می‌آید
- به هر ترکیب نمره می‌دهد و ترکیب‌های ضعیف (زیر ۶ از ۱۰) فرستاده نمی‌شوند

پیامی که این‌طور ساخته شده این علامت را دارد:

```
🤖 انتخاب هوش مصنوعی
```

برای روشن کردنش:

۱. در سایت [console.anthropic.com](https://console.anthropic.com/) یک کلید بسازید.

۲. کلید را در فایل `.env` جلوی این خط بنویسید:

```
ANTHROPIC_API_KEY=
```

مدل پیش‌فرض `claude-haiku-5-5` است که ارزان‌ترین مدل است؛ هر نوبت (هر سه ساعت) کمتر از یک سنت. مدل، زبان متن و نمره‌ی حداقل در بخش `[ai]` فایل تنظیمات است.

سرورهای Anthropic به آی‌پی ایران جواب نمی‌دهند، پس VPN باید روشن باشد. اگر کلید نباشد، VPN قطع باشد یا هر خطای دیگری پیش بیاید، ربات بی‌صدا به روش کلمه‌ای برمی‌گردد و ترکیب‌ها باز هم می‌آیند.

### کلیپ‌های کانال‌های تلگرام فارسی در ترکیب‌ها

به‌طور پیش‌فرض کلیپ ترکیب‌ها فقط از تیک‌تاک، اینستاگرام و یوتیوب می‌آید. اگر می‌خواهید کلیپ کانال‌های تلگرام هم بیاید، در بخش `[combos]` این را اضافه کنید:

```
clip_platforms = ["tiktok", "instagram", "youtube", "telegram"]
```

این کار وقتی هوش مصنوعی روشن است بیشتر به درد می‌خورد، چون متن‌های آماده از توییت‌های انگلیسی‌اند.

اگر ویدیو دانلود نشد یا از ۴۵ مگابایت بزرگ‌تر بود، همان پیام با عکس پیش‌نمایش و لینک می‌آید.

کلیپ‌ها از تیک‌تاک، اینستاگرام و شورت‌های یوتیوب می‌آیند و در هر نوبت از هر پلتفرم یکی فرستاده می‌شود تا هر سه سهم داشته باشند.

متن‌ها از بین توییت‌ها انتخاب می‌شوند، ولی نه هر توییتی: فقط جمله‌هایی که شکل کپشن میم دارند. یعنی کوتاه‌اند، لینک و تبلیغ ندارند، و با الگوهایی مثل «when…» یا «how it feels…» شروع می‌شوند. کلیپ‌ها هم از بین ویدیوهای پربازدید همان چند ساعت انتخاب می‌شوند.

اگر متن و کلیپ موضوعشان هم یکی باشد، آن ترکیب امتیاز بیشتری می‌گیرد و اول فرستاده می‌شود.

هر کلیپ و هر متن فقط یک بار پیشنهاد می‌شود، تا یک کلیپ پربازدید هر سه ساعت با یک متن تازه دوباره نیاید.

### بسته‌ی هم‌موضوع

گاهی چند پست از پلتفرم‌های مختلف درباره‌ی یک ماجرا هستند. ربات این‌ها را جدا می‌کند و با هم می‌فرستد تا بتوانید یک کلیپ چندتکه یا یک کاروسل بسازید. برای اینکه گروه‌بندی الکی نشود، پست‌ها باید بیشتر از یک کلمه‌ی مشترک داشته باشند یا موضوعشان همان لحظه در ایکس ترند باشد.

تنظیماتش در بخش `[combos]` فایل تنظیمات است: تعداد ترکیب‌ها، فاصله‌ی زمانی، و حداکثر حجم ویدیو.

### فیلتر خنده‌دار و باحال

ربات پست‌های خبری، سیاسی و ناراحت‌کننده را کنار می‌گذارد و اول سراغ چیزهای خنده‌دار و باحال می‌رود. این کار با دو فهرست کلمه انجام می‌شود که آخر فایل تنظیمات هستند و هر وقت خواستید می‌توانید کم و زیادشان کنید:

- `funny_keywords` نشانه‌های روشن پست خنده‌دار، مثل «lol»، «😂» یا «خنده‌دار». یکی کافی است
- `weak_funny_keywords` نشانه‌های ضعیف، مثل «bro»، «🔥» یا «cat». تنها چیزی نمی‌گویند؛ دو تا با هم یعنی پست احتمالاً باحال است
- `blocked_keywords` نشانه‌های پست خبری یا ناراحت‌کننده، مثل جنگ و سیاست، به انگلیسی و فارسی. پستی که یکی از این‌ها را داشته باشد اصلاً فرستاده نمی‌شود
- `soft_blocked_keywords` کلمه‌های دوپهلو مثل «dead» یا «police». در خبر جدی‌اند ولی در شوخی اصطلاح‌اند («I'm dead 💀»). فقط وقتی پست را حذف می‌کنند که هیچ نشانه‌ی خنده‌ای نداشته باشد

کلمه‌ها فقط به‌صورت کامل پیدا می‌شوند؛ یعنی «فوت» جلوی «فوتبال» را نمی‌گیرد و «war» جلوی «warm» را.

اگر خواستید این فیلتر خاموش شود، در همان فایل مقدار `skip_serious` را `false` کنید.

اگر بخواهید ترند یوتیوب به جای ده کانال شما، از کل یوتیوب حساب شود، یک کلید رایگان از گوگل لازم است. اجباری نیست:

از [console.cloud.google.com](https://console.cloud.google.com/) یک پروژه بسازید، این سرویس را فعال کنید:

```
YouTube Data API v3
```

بعد از این مسیر یک کلید بسازید:

```
Credentials → Create API key
```

کلید را مثل دو رمز قبلی در گیت‌هاب اضافه کنید، با این اسم:

```
YOUTUBE_API_KEY
```

این کلید رایگان است و کارت بانکی نمی‌خواهد.

## اینستاگرام روی کامپیوتر خودت اجرا می‌شود

سایت‌هایی که اطلاعات اینستاگرام را از آن‌ها می‌گیریم، آی‌پی سرورهای گیت‌هاب را بلاک می‌کنند (خطای ۴۰۳). خودِ اینستاگرام هم بدون اکانت جواب نمی‌دهد. ولی از اینترنت خانگی شما هر دو درست کار می‌کنند.

برای همین کار بین دو جا تقسیم شده:

- **گیت‌هاب:** پست‌های تازه‌ی یوتیوب و تیک‌تاک، و گزارش ترند — همیشه، حتی وقتی کامپیوتر خاموش است
- **کامپیوتر شما:** پست‌های تازه‌ی اینستاگرام و **ترکیب‌های پیشنهادی**، هر نیم ساعت — وقتی کامپیوتر روشن است

ترکیب‌ها هم روی کامپیوتر شما ساخته می‌شوند، چون فقط آنجا هر چهار پلتفرم در دسترس‌اند و کلیپ اینستاگرام هم می‌تواند وارد ترکیب شود.

روی ویندوز یک کار زمان‌بندی‌شده با این اسم ساخته شده:

```
MemeBot-Instagram
```

هیچ پنجره‌ای باز نمی‌شود و گزارش هر اجرا در این فایل نوشته می‌شود:

```
local-run.log
```

برای دیدن چند خط آخرش در پاورشل (بدون `-Encoding UTF8` فارسی‌اش به‌هم‌ریخته نشان داده می‌شود):

```bash
Get-Content C:\Users\mhmdn\Desktop\youtube\local-run.log -Tail 20 -Encoding UTF8
```

برای دیدن وضعیتش در پاورشل:

```bash
Get-ScheduledTaskInfo -TaskName "MemeBot-Instagram"
```

عدد `LastTaskResult` اگر `0` باشد یعنی اجرای آخر بدون خطا بوده. اگر `1` باشد یعنی در آن اجرا تلگرام در دسترس نبوده (VPN قطع بوده). پیام‌هایی که نرسیده‌اند در اجرای بعدی فرستاده می‌شوند.

اگر VPN شما حالت «پروکسی سیستم» دارد (مثل v2rayN، NekoBox یا Hiddify)، ربات خودش از همان پروکسی ویندوز استفاده می‌کند و تنظیم جداگانه‌ای لازم نیست.

اجرای روی کامپیوتر فقط برای خرابی اینستاگرام هشدار می‌دهد. یوتیوب، تیک‌تاک و ایکس را نسخه‌ی گیت‌هاب زیر نظر دارد، پس با هر قطعی VPN هشدار تکراری نمی‌گیرید.

اگر اینستاگرام چند بار پشت سر هم کار نکند و در هشدار نوشته باشد «Cloudflare» یا «blocked»، یعنی سایت منبع آی‌پی VPN شما را بلاک کرده. سرور یا لوکیشن VPN را عوض کنید؛ اجرای بعدی خودش دوباره امتحان می‌کند و وقتی درست شد خبر می‌دهد.

### راه مطمئن برای اینستاگرام: کوکی یک اکانت فرعی

بدون لاگین، اینستاگرام از بیشتر آی‌پی‌ها جواب نمی‌دهد و سایت‌های واسطه هم پشت Cloudflare بلاک می‌شوند. در لاگ‌های این ربات، اینستاگرام از هر پنج اجرا حدود چهار بار شکست می‌خورد. با کوکی یک اکانت لاگین‌شده، ربات مستقیم از خود اینستاگرام می‌خواند.

از یک **اکانت فرعی** استفاده کنید، نه اکانت اصلی خودتان؛ اینستاگرام ممکن است اکانتی را که خودکار خوانده می‌شود محدود کند.

۱. در مرورگر کامپیوتر با اکانت فرعی وارد instagram.com شوید.

۲. کلید `F12` را بزنید، به این مسیر بروید:

```
Application → Cookies → https://www.instagram.com
```

(در فایرفاکس اسم تب `Storage` است.)

۳. مقدار ردیف `sessionid` را کپی کنید و در فایل `.env` جلوی این خط بنویسید:

```
INSTAGRAM_SESSIONID=
```

این کوکی مثل رمز عبور آن اکانت است؛ آن را به کسی ندهید و در گیت‌هاب آپلود نکنید (فایل `.env` آپلود نمی‌شود). اگر بعد از مدتی هشدار «cookie has expired» آمد، دوباره وارد شوید و کوکی تازه را جایگزین کنید.

برای حذف این کار زمان‌بندی‌شده:

```bash
Unregister-ScheduledTask -TaskName "MemeBot-Instagram" -Confirm:$false
```

و برای ساختن دوباره‌اش:

```bash
$a = New-ScheduledTaskAction -Execute "C:\Users\mhmdn\Desktop\youtube\venv\Scripts\pythonw.exe" -Argument '"C:\Users\mhmdn\Desktop\youtube\main.py" --only instagram,tiktok,youtube,x,telegram --uploads instagram --trend-platforms instagram --state state-local.json' -WorkingDirectory "C:\Users\mhmdn\Desktop\youtube"; $t = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Minutes 30); Register-ScheduledTask -TaskName "MemeBot-Instagram" -Action $a -Trigger $t -Force
```

اجرای محلی فهرست جداگانه‌ی خودش را در `state-local.json` نگه می‌دارد، برای همین با نسخه‌ی گیت‌هاب قاطی نمی‌شود و پست تکراری نمی‌گیرید.

## اگر چیزی کار نکرد

راه‌های گرفتن اطلاعات از اینستاگرام، تیک‌تاک و ایکس غیررسمی‌اند، چون این سه برنامه راه رسمیِ رایگان ندارند. ممکن است یک روز عوض شوند یا موقتاً از کار بیفتند.

نگران نباشید: اگر یکی از این چهار برنامه سه بار پشت سر هم جواب ندهد، خود ربات در تلگرام به شما هشدار می‌دهد و وقتی دوباره درست شد، آن را هم خبر می‌دهد. بقیه‌ی برنامه‌ها در این مدت به کارشان ادامه می‌دهند.

اگر همه‌ی منابع با هم جواب ندهند، مشکل از اینترنت یا VPN خود سیستم است نه از منابع، و برای آن هشداری فرستاده نمی‌شود.

خوراک رسمی یوتیوب گاهی چند ساعت از کار می‌افتد (خطای ۴۰۴). در این مدت ربات شورت‌ها را مستقیم از صفحه‌ی کانال برمی‌دارد، پس پست تازه‌ای از دست نمی‌رود.

اگر موقع اجرا روی کامپیوتر خودتان این پیام را دیدید، مشکل از ربات نیست و ارتباط با تلگرام قطع شده است. VPN را روشن یا عوض کنید و دوباره امتحان کنید:

```
ارتباط با سرور تلگرام برقرار نشد
```

ربات خودش چهار بار تلاش می‌کند و اگر قطعی کوتاه باشد، خودش جبران می‌کند. پست‌هایی که در این مدت نرسیده‌اند از بین نمی‌روند و در اجرای بعدی فرستاده می‌شوند.

ممکن است سرورهای گیت‌هاب برای اینستاگرام یا تیک‌تاک بلاک باشند. در این صورت می‌توانید ربات را روی کامپیوتر خودتان زمان‌بندی کنید تا هر نیم ساعت اجرا شود. این دستور را در پاورشل بزنید:

```bash
schtasks /Create /SC MINUTE /MO 30 /TN "MemeBot" /TR "\"C:\Users\mhmdn\Desktop\youtube\venv\Scripts\python.exe\" \"C:\Users\mhmdn\Desktop\youtube\main.py\""
```

برای پاک کردن این زمان‌بندی:

```bash
schtasks /Delete /TN "MemeBot" /F
```

در این حالت ربات فقط وقتی کار می‌کند که کامپیوتر روشن و به اینترنت وصل باشد.

## اطلاعات از کجا می‌آید؟

| برنامه | پست‌های تازه | گزارش ترند |
|---|---|---|
| یوتیوب | خوراک رسمی خود یوتیوب | کانال‌های شما، یا با کلید گوگل کل یوتیوب |
| اینستاگرام | سایت‌های imginn و imgsed، و در صورت خرابی خود اینستاگرام (فقط روی کامپیوتر خودتان) | پیج‌های شما |
| تیک‌تاک | برنامه‌ی yt-dlp | سایت tikwm.com |
| ایکس | سرویس عمومی FxTwitter | همان سرویس |
| تلگرام | صفحه‌ی عمومی t.me/s کانال | کانال‌های شما |

از این پنج تا، یوتیوب و تلگرام رسمی و مطمئن‌اند. بقیه راه‌های رایگانی هستند که کار می‌کنند ولی ضمانت همیشگی ندارند. راه رسمی ایکس پولی است و برای هر توییتی که خوانده شود پول می‌گیرد.
